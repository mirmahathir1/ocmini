# OCMINI
This is my repo on building a minimal AI agent with python mimicking opencode (https://github.com/anomalyco/opencode)- the current 2nd highest starred open-source AI agent available on the internet. 

# Objective
The objective is to learn and understand how modern AI agents work.

## What I am allowed to do
I am allowed to use every option possible that are 100% free to develop the code- including but not limited to:
- open source agents
- free language models (limited term or not)
- looking at opencode github repo

## What I am not allowed to do
These are the things I am strictly prohibited from using
- paid subscription of any AI

The project scope is defined with the help of Claude Code (ocmini-spec.md).
